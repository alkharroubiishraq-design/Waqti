# وقتي · Waqti

تطبيق ويب (PWA) لتنظيم الوقت لكل الناس. بيجمع العبادة والعمل والدراسة والصحة والعائلة بجدول يومي ذكي واحد.
**كل البيانات بتنحفظ على جهاز المستخدم بس**، وما في أي سيرفر.

## الميزات
- **الإعداد الأول:** اللغة، والديانة (إسلام، أو مسيحية، أو بدون)، والمدينة أو الموقع، والدوام، والنوم.
- **للمسلم:**
  - الصلوات الخمس بتنحسب على الجهاز بمكتبة [Adhan](https://github.com/batoulapps/adhan-js)، وفيها ١٢ طريقة حساب ومذهب العصر.
  - القبلة مع بوصلة الهاتف، والتاريخ الهجري.
  - السحور والإفطار برمضان، وحجز وقت صلاة الجمعة، والمناسبات الإسلامية.
- **للمسيحي:**
  - قداس أسبوعي باليوم والوقت اللي بتختاره، ومواعيد الكنيسة.
  - الأعياد حسب الفصح الغربي أو الشرقي، والأعياد الثابتة بالتقويم الغريغوري أو اليولياني.
- **المهام:** أولويات، وتكرار، وتذكير، ومهام بدون تاريخ.
- **الدراسة:** مؤقّت بومودورو، والمواد، وجدول الحصص، والامتحانات والواجبات.
- **الصحة:** الماء، والتمارين، والنوم.
- **العادات:** شبكة آخر ٧ أيام، مع عدّاد للأيام المتتالية.
- **العائلة:** أعياد الميلاد (بتتكرر كل سنة)، والزيارات، والمناسبات.
- **نشاطات مخصّصة:** كل نشاط إلو اسم ولون وأيقونة.
- **الجدول اليومي:** خط زمني، والمهام بتنسحب وتنحط بمكانها، باللمس أو بالماوس.
- **الجدولة الذكية:**
  - بتقترح أنسب وقت فاضي، وزر "رتّب يومي" بيوزّع المهام حسب أولويتها.
  - إذا انحطّت مهمة فوق صلاة أو قداس أو نوم، بتنتقل لحالها لأقرب وقت فاضي.
- **التذكيرات:** نغمة هادئة، أو ملف صوتي بيختاره المستخدم (مثلاً الأذان). وفي كمان تصدير `.ics` لتقويم الهاتف.
- **الإحصائيات:** "وين راح وقتك"، ونسبة الالتزام (المهام والصلوات والعادات والماء)، والوقت المنتج بكل يوم.
- **الواجهة:**
  - ٢٨ لغة، مع دعم كامل لليمين لليسار (العربي والفارسي والأردو والعبري).
  - وضع داكن، وبيشتغل بدون إنترنت.

## التشغيل
ما بيحتاج أي بناء. بيكفي تفتحه بخادم ملفات ثابت:
```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```
للنشر: فعّل **GitHub Pages** من إعدادات المستودع على فرع `main`، المجلد الجذر.

## ملاحظات مهمة
- **التنبيهات:**
  - بتشتغل والتطبيق مفتوح أو بالخلفية.
  - المتصفحات ما بتسمح لتطبيق ويب بدون سيرفر يبعت تنبيه بوقت محدد وهو مسكّر كلياً، خصوصاً على الآيفون.
  - الحل الموجود هلأ: زر "تصدير إلى التقويم"، فتقويم الهاتف بيذكّر حتى والتطبيق مسكّر.
  - الحل الكامل بيجي مع نسخة Flutter الأصلية.
- **التاريخ الهجري:** حسب أم القرى، وممكن يختلف يوم عن رؤية الهلال المحلية.
- **الترجمات:**
  - العربي والإنجليزي مكتملين.
  - باقي اللغات (٢٦) فيها الواجهة الأساسية: التنقل، والإعداد، والجدول، والصلوات والأعياد، والنماذج. النصوص الثانوية بتطلع بالإنجليزي.
  - كلها ترجمة مبدئية، ولازم يراجعها ناس بيحكوا هاي اللغات قبل النشر الرسمي.
- **الأذان:** ما في ملف أذان مسجّل مضمّن بالتطبيق بسبب الحقوق، والمستخدم بيرفع الملف اللي بيحبه.

## البنية
```
index.html, manifest.webmanifest, sw.js   الواجهة الأساسية، وملف التثبيت، والعمل بدون إنترنت
css/app.css                               التصميم (فاتح وداكن، يمين ويسار)
js/app.js, router.js, ui.js               التشغيل والتنقل والمكونات
js/store.js                               التخزين المحلي (localStorage + IndexedDB للصوت)
js/worship.js                             الصلاة، والقبلة، والهجري، والفصح الشرقي والغربي
js/schedule.js                            المواعيد الثابتة، والتكرار، والجدولة الذكية
js/notify.js, ics.js                      التذكيرات وتصدير التقويم
js/views/*.js                             الشاشات
i18n/*.json                               الترجمات
vendor/adhan.js                           مكتبة Adhan (رخصة MIT)
```

## الخطوات الجاية
نسخة Flutter (Google Play و App Store)، وحساب ومزامنة اختيارية، وأديان ولغات إضافية، ونسخة مدفوعة.
